# NotebookLM × 國小綜合活動教師工作坊

這是一份提供國小綜合活動領域教師使用的 150 分鐘互動式研習網站，協助教師從教材匯入、教材理解與心智圖，逐步完成教案、簡報、學習單、測驗與核心概念影片。

## 網站特色

- 8 個研習模組與完整操作流程
- 初階／進階任務分流
- 可一鍵複製的繁體中文提示詞
- 進度勾選、個人筆記與成果摘要
- 支援手機、平板與電腦操作

進度與筆記只會儲存在使用者目前的瀏覽器中，不會上傳至伺服器。

## 使用方式

直接開啟 GitHub Pages 網站，依左側模組順序操作即可。若要在本機使用，也可以下載本儲存庫後直接開啟 `index.html`。

## 教學提醒

NotebookLM 的介面與功能可能隨版本更新而調整。使用 AI 產出的教案、教材與評量前，仍應由教師依學生需求、課程目標與資料來源進行檢核。
